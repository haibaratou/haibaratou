# エティモリンゴ：レキシコピア Prototype

エティモリンゴ：レキシコピア is the formal title for the mobile-first casual game prototype about collecting and playing with etymology characters based on Proto-Indo-European roots. Wild Wordopia remains an older working codename in archived prototype filenames and legacy material.

This repository currently focuses on the standalone HTML game prototype. LLM scanning, generated scene text, and online battles are out of scope for this prototype phase.

## Structure

- `app/index.html` - Current mobile HTML prototype.
- `app/index-magicus.html` - MAGICUS-style reading layout prototype.
- `app/word-kingdom-proto.html` - CookieRun Kingdom-inspired word-production kingdom prototype.
- `assets/planning/` - Planning images extracted from the concept deck.
- `docs/analysis/capybara-go-ui-analysis.md` - Capybara Go layout/UI/tempo analysis for reproduction.
- `docs/analysis/capybara-go-contact-sheet.jpg` - Contact sheet of the latest Capybara Go capture set.
- `docs/pitch/proposal-excerpt.pptx` - Project proposal / planning deck excerpt.
- `references/videos/` - Reference mobile game recordings for future UI analysis.
- `references/captures/` - Captures from reference mobile games for future UI analysis.

## Notes

- `references/` is source material for UI analysis and should not be treated as in-game assets.
- Capybara Go is the primary reference for adventure layout, UI density, and progression tempo.
- The old duplicated `html/` sub-repository was removed. Use the root repository as the source of truth.
