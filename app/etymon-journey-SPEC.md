# 遠征絵日記「エティモリンゴ」 作り直し指示書(Codex向け)

現行試作 `app/etymon-journey.html` を、同じコンセプトで **Steam品質のUI** に作り直す。
成果物: `app/etymon-journey.html` の置き換え(単一HTML・依存なし・file://直開き可)。
現試作はイベント分岐・文言の参考として読んでよいが、内容の改良は自由。見た目は流用しない。

---

## 1. ゲームのコンセプト(発注者指定)

- **編成**: エティモン(語根キャラ。呼称は「エティモン」。名前は `app/data/wilds.csv` の正式名)を選ぶと、
  そのエティモンの**家系の英単語カードが自動でかばんに入る**。
  出発枠は4。候補は枠より多くし、誰を連れて行くかの選択が生まれるようにする。
  なかまが多いほど夕ごはんも多く必要(食料コストがパーティ人数で増える)。
- **放置遠征**: 持たせた英単語とエティモン編成によって結果が変化する数日間の旅。
- **リアルタイム絵日記**: 旅の経過が**縦スクロール漫画**としてその場で展開される。
  コマは `assets/` の実素材を合成して描く(背景+キャラ+英単語カード)。
  持ち込んだアイテムによってコマの中身が変わる(キャベツの部分がビスケットになる等)。
- **タップで進む**。テキストは**1文字ずつ**出現し、タップで即時全文表示。
- **情報はすべて流れに刻む**: アイテムの使用、HPの減少などをイベントチップとして漫画の流れに表示。
- **HUD**: HPはハート❤式(バーではなくアイコン)。満腹度、士気(きぶん)も同様。
  所持アイテムが減っていくのが見える。入手した宝(英単語)の置き場を設ける。
- **日英切替ボタン**(English / English+日本語 / 日本語)。
- **ヒントは赤字**。タップで「聞いたことば」に収集され、次の遠征の手がかりになる。
- **食料**: 食べものがないと遠征途中でみな力尽きる。食べもの+シェフで相乗効果(遠征距離が伸びる)。
- **疑いイベント**: 何らかの疑いをかけられても、証拠(evidence)や目撃者(witness)の英単語を持っていれば回避できる。
- **動物の英単語**は連れて行くと協力してくれる。なかまは食べない。
- **保存**: 冒険はすべて「第N回遠征日記」として保存され、本だなからいつでも読める。
- 初回シナリオの山場: **絶対に見られたくない透明人間(invisible)の打倒**。
  見る系の英単語(vision, witness など)で倒せる。

## 2. レイアウト(発注者指定)

- **完全固定レイアウト**: 1920×1080 のキャンバスを等倍スケール表示(IP360 の fitStage 方式)。
  ウィンドウのサイズ・縦横比を変えてもレイアウトは一切変形しない。
- コマの**縦横比は固定**。
- 縮小表示を前提に、文字は1920キャンバス基準で大きく。
- Steam前提。横に大きな余白を作らない。UIを重ねない。巨大な空白を作らない。

## 3. データと素材の規範(発注者指定)

- **語根・意味は `app/data/pie/` の実レコードに従う。捏造しない。**
  (既知の注意点: DBの `light` は legʷh-「軽い」。leuk-「光」の家系ではない)
- **名前は正式データ**: エティモンの名前・色は `app/data/wilds.csv`(カプト/アーネ/バーファ/グウェイ/
  オイノ/レーグ/ウェイド/イェート/モーリ/メーン/ドー)。語源解説は `app/data/etymon.csv`。
- **素材は `assets/` の実物を使う**。キャラ画像は**透過済みのもののみ**
  (`assets/chara/` には白背景の未完成画像が38枚混在。四隅のアルファで判別できる)。
- 文章は短く具体的に。気取った比喻表現は不要。

## 4. 検証済みの在庫(そのまま使える)

エティモンと家系デッキの例(全18語、DB照合済み・`assets/word/` に絵あり・キャラ絵は透過確認済み):

| エティモン | 語根 | キャラ絵 | 家系の英単語(DB表記) |
|---|---|---|---|
| カプト | *kaput- あたま | T_ch_kaput_head.png | cabbage(正史: etymon.csv)/ chef(kaput-)/ captain(kaput-) |
| ウェイド | *weid- 見る・知る | T_ch_weid_see.png | vision / witness / video(すべて weid-) |
| バーファ | *bha- 話す | T_ch_bha_speak.png | fable(bhā-2)/ prophet(per1+bhā-2)/ fame(bhā-2) |
| グウェイ | *gwei- 生きる | T_ch_gwei_live.png | quick / revive(re-+gwei-)/ survive(uper+gwei-) |
| レーグ | *reg- まっすぐ | T_ch_reg_straight.png | direct(dwis-+reg-)/ right / rule(reg-) |
| ドー | *do- 与える | T_ch_do_give.png | donation(dō-)/ pardon(per1+dō-)/ date(dō-) |

ほかに透過済みキャラ絵があるエティモン: アーネ(T_ch_ane_breath)/ オイノ(T_ch_oi-no_one)/
イェート(T_ch_ye_throw)/ モーリ(T_ch_mori_water)/ メーン(T_ch_men_think)。追加は自由
(その場合も家系の語は DB照合し、絵の有無を確認すること)。

- 単語DB: `app/data/pie/words.json`(17,505語: w/p[]/ja/pos/g/r)、`roots.json`、`tags.json`(WordNet分類)
- 背景: `assets/ground/`(T_BG_base_expedition, _night, _rock, T_BG_base_sea ほか)
- 英単語の絵: `assets/word/`(3,960枚)。絵のない語はカード風の仮表示にする
- 敵キャラ素材: `assets/chara/T_ch_enemy_01.png`, `T_ch_stage1_boss.png`(透過済み)
- UI部材: `assets/ui/`
